# Interárea Física — Laboratório da Água + Biofiltro Experimental

Aplicação web desenvolvida em PHP para o projeto interdisciplinar de Física, Química e Biologia.

## Objetivo

Simular um laboratório digital de qualidade da água, classificar parâmetros medidos e calcular a eficiência experimental de um biofiltro a partir de valores antes e depois do tratamento.
